# 2024 Monaco GP Baseline

This folder contains early practice scripts and figures created while learning Formula 1 data workflows with OpenF1 and FastF1.

These files are kept as an archived baseline rather than a polished analysis. They show the starting point of the portfolio before the repository moved toward a more structured race-analysis workflow.

## Contents

- `scripts/hello_f1.py`: first OpenF1 lap-time extraction example.
- `scripts/monaco_analysis.py`: basic Verstappen stint/lap-time visualisation with FastF1.
- `scripts/monaco_top6.py`: top-six Monaco lap-time comparison with red-flag annotation.
- `figures/`: generated figures from the early scripts.

Future public-facing race analyses should follow the more complete structure used in `../2026_belgian_friday_analysis`.
