# Formula 1 Strategy Analysis Portfolio

## Overview

This repository is a long-term Formula 1 data science and race strategy analysis portfolio.

It focuses on using public Formula 1 data to study race strategy, lap time performance, tyre degradation, pit stop decisions, telemetry patterns, and predictive modelling.

The project is designed as a continuous research and portfolio-building effort rather than a collection of isolated analysis scripts.

The aim is to connect motorsport questions with statistical reasoning, reproducible Python workflows, clear visualisation, and public-facing technical communication.

## Portfolio Goals

This portfolio is designed to demonstrate:

- Statistical reasoning
- Python-based data analysis

- Motorsport-specific analytical thinking

- Long-term commitment to Formula 1 and sports analytics

This project reflects my long-term interest in applying statistics, computer science, and data analysis to Formula 1, motorsport strategy, performance analysis, and sports analytics problems.

## Featured Analysis Areas

This portfolio is organised around several recurring Formula 1 analytics themes.

| Area | Example Questions | Methods | Skills Demonstrated |
| --- | --- | --- | --- |
| Race Pace Analysis | How did race pace evolve across stints? Which drivers maintained consistent pace? | Lap time cleaning, stint comparison, pace delta plots | Data cleaning, performance analysis, visualisation |
| Tyre Degradation | How did tyre age and compound choice affect lap time? | Tyre age features, stint comparison, degradation regression | Statistical modelling, feature engineering |
| Pit Stop Strategy | Was a pit stop made too early or too late? | Pit window analysis, position change tracking | Strategy reasoning, decision analysis |
| Undercut / Overcut | Did stopping earlier or later create an advantage? | Lap delta comparison, rival analysis | Tactical analysis, trade-off reasoning |
| Safety Car / Red Flag Impact | How did interruptions change race outcomes? | Event comparison, scenario analysis | Race context analysis |
| Qualifying vs Race Pace | Did qualifying performance translate into race pace? | Pace comparison, sector analysis | Comparative analysis |
| Telemetry Analysis | Where did drivers gain or lose time? | Speed, throttle, brake, DRS analysis | Engineering-style data analysis |
| Driver Style Characterisation | How do drivers differ in driving patterns? | Feature extraction, clustering, PCA | Exploratory modelling |
| Predictive Modelling | Can pace, tyre life, or strategy outcomes be predicted? | Regression, classification, validation | Machine learning |
| Race Simulation / Strategy Optimisation | How would alternative strategies perform? | Simulation, scenario testing | Decision modelling |

## Project Workflow

Each analysis follows a structured workflow:

1. Identify a motorsport question
2. Record the initial observation
3. Formulate a testable hypothesis
4. Define required data
5. Choose an appropriate analysis method
6. Generate reproducible outputs
7. Interpret the results
8. Create public-facing documentation

This workflow connects race observation with evidence-based analysis.
